# Tomsen - Application de gestion financière

Projet réalisé dans le cadre de ma formation de testeur logiciel, autour d'une application de gestion financière développée dans un contexte Agile.

## Mon rôle

Dans ce projet, j'ai travaillé en tant que consultante test.

Mes missions ont consisté à :

* réaliser des revues d'exigences ;
* analyser les fonctionnalités et identifier les besoins de test ;
* définir une stratégie de test ;
* concevoir un cahier de recette ;
* identifier et prioriser les scénarios selon leur criticité.

## Contexte du projet

Tomsen est une application de gestion financière comprenant notamment plusieurs fonctionnalités liées :

* à l'authentification ;
* aux données bancaires ;
* aux documents ;
* aux transactions ;
* à la consommation ;
* à l'espace conseiller ;
* à la double authentification.

Le projet a été réalisé selon une organisation Agile, en collaboration avec différents rôles du projet.

## Livrables

Les travaux réalisés dans le cadre du projet comprennent :

* les revues d'exigences ;
* la stratégie de test ;
* le cahier de recette.

## Outils utilisés

* Excel
* Notion
* Jira
* DevTools
* Cypress
* GitHub

## Objectif du projet

L'objectif était de préparer une campagne de tests permettant de vérifier la conformité des fonctionnalités de l'application, d'identifier les risques et de définir les tests à réaliser avant le déploiement.
